## from\_scratch

As the name suggests, this repo is all about building things with pure math—from the ground up. Whether it’s a neural network in Python or a regression model in C++, I’m diving into every equation, every line of code, and having fun on my way to becoming invincible <3.

---

### 📂 Repository Structure

```
harshitjais14-from_scratch/
```
